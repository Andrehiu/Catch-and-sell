# Catch & Sell

A cozy phone game: catch fish from around the world and sell them in your own shop.

**▶ Play it: https://andrehiu.github.io/catch-and-sell/**

## Add to home screen
- **iPhone:** open the link in **Safari** → Share → **Add to Home Screen**.
- **Android:** open the link in **Chrome** → ⋮ menu → **Install app** (or *Add to Home screen*).

After one online visit the game also works offline. When a new version is out, a "New version — tap to update" bar appears at the top.

## One-time GitHub setup
Repo **Settings → Pages → Source: GitHub Actions**. After that, every push to `main` (except docs-only changes) runs tests, builds and deploys to Pages. CI (`.github/workflows/ci.yml`) runs build + unit + e2e on every push and PR.

- Design: [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md)
- Roadmap: [ROADMAP.md](ROADMAP.md)

## How to run
```bash
npm install
npm run dev        # dev server (open on a phone-sized window; add ?debug=1 for fast timers)
npm run build      # type-check + production build
npm test           # Vitest unit tests (game logic)
npm run e2e        # Playwright e2e at 390×844 (add -- --trace off unless debugging)
```
Debug mode: append `?debug=1` (optionally `&seed=123`) — sells every 0.5 s, bites within 0.3 s, and exposes `window.__debug` (force bite/catch) for tests. Never on by default.
Saves live in `localStorage` under `catchandsell.save.v1`.

PWA notes: icons are generated by `node scripts/gen-icons.mjs` (pixel fish, style-B palette) into `public/icons/`. `npm run build` stamps the git commit into `sw.js` (cache name) and `version.json`. The service worker registers in production builds only (`?sw=0` opts out).
